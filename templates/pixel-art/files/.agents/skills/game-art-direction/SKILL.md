# Game art direction

1. Read `references/STYLE_GUIDE.md` and the current asset manifest.
2. Create a structured brief with asset ID, in-game use, dimensions, palette, silhouettes, animation frames, and exclusions.
3. Request candidates through provider-neutral Engine MCP asset tools.
4. Show cost and outbound references before any paid or remote job.
5. Keep candidates as drafts until the developer selects one.
6. Process and import the selection through a ChangeSet, recording hashes, provider/model, parameters, rights, and transformations.
