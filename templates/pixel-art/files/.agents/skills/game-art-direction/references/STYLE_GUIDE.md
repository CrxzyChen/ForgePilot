# {{PROJECT_NAME}} style guide

- Working resolution: 320 × 180 logical pixels, integer scaled.
- Tile size: 16 × 16 logical pixels.
- Palette: begin with no more than 24 opaque colors plus transparency.
- Silhouette: player, enemies, projectiles, terrain, and objectives must remain distinct at 1× scale.
- Lighting: one consistent top-left light direction; no smooth gradients in gameplay sprites.
- Animation: explicit frame grid, pivot, duration, and loop behavior for every sheet.
- References: project-owned or licensed references only; never request imitation of a living artist or protected game asset.
